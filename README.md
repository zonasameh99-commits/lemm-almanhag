# لمّ المنهج 🌿
مخطط مذاكرة عربي (RTL) للطلاب في مصر — HTML وCSS وJavaScript فقط، بدون خادم أو إنترنت.

## التشغيل
1. فكّ ضغط الملف.
2. افتح `index.html` بالمتصفح (كروم، فايرفوكس، سفاري، إيدج). هذا كل شيء.

## المزايا
- **المواد والدروس:** أضف موادك ودروسها، وتُحسب نسبة الإنجاز تلقائيًا. بحث وتصفية.
- **المهام:** مهام يومية بتاريخ ومادة اختيارية.
- **الامتحانات:** عدّ تنازلي بالأيام.
- **التركيز:** مؤقّت بومودورو قابل للتعديل، وتُسجَّل الجلسات المكتملة.
- **الإحصائيات:** رسم أسبوعي لدقائق التركيز وتقدّم المواد.
- **الوضع الداكن/الفاتح** من الإعدادات.
- **نسخة احتياطية:** تصدير واستيراد JSON من الإعدادات.

## البيانات
تُحفظ في متصفحك فقط (localStorage). مسح بيانات المتصفح يحذفها، فصدّر نسخة احتياطية دوريًا.

## الملفات
- `index.html` — الهيكل
- `css/style.css` — التصميم
- `js/app.js` — المنطق
